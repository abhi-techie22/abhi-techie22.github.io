# UniSafeX Website

Static website for UniSafeX, the tourism safety companion for visitors in India.

## Contents

- `dist/index.html` - complete single-page website
- `dist/heritage.jpg` - hero and app preview image
- `dist/favicon.svg` - site favicon
- `dist/privacy.html` - privacy policy
- `dist/terms.html` - terms of service
- `dist/cancellation-refund.html` - cancellation and refund policy
- `dist/community-guidelines.html` - rules for reviews, replies, and photos
- `dist/support.html` - support, grievance, and escalation policy
- `dist/account-deletion.html` - external account and data deletion request instructions
- `dist/policy.css` - shared policy-page styles
- `.openai/hosting.json` - Sites hosting configuration for the live deployment
